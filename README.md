# 🌐 Smart Translate SPA - مترجم هوشمند اسناد سمت کاربر

> **نرم‌افزار مدرن، امن و تک‌صفحه‌ای (SPA & Desktop App) برای ترجمه هوشمند اسناد با پشتیبانی از مدل‌های زبانی محلی (Ollama) و سرویس‌های ابری با بهینه‌سازی اختصاصی نگارش، کنتراست بالا، پشتیبانی کامل یونیکد و تایپوگرافی Editorial فارسی.**

## ✨ ویژگی‌های کلیدی

- **🔒 امنیت و حریم خصوصی ۱۰۰٪ سمت کاربر (Client-Side):** تمام مراحل خواندن، استخراج متن و پردازش اسناد در مرورگر یا نرم‌افزار دسکتاپ انجام شده و هیچ فایلی به سرور خارجی ارسال نمی‌گردد.
- **🖥️ پشتیبانی از نسخه دسکتاپ (Electron):** امکان اجرای مستقل در قالب نرم‌افزار دسکتاپ ویندوز بدون نیاز به مرورگر با قابلیت ساخت خروجی `.exe` (نصبی و پرتابل).
- **🤖 پشتیبانی از مدل‌های هوش مصنوعی لوکال (Ollama):** اتصال مستقیم به مدل‌های قدرتمندی نظیر `llama3`، `qwen2.5`، `gemma2`، `mistral` و مدل‌های تخصصی ترجمه.
- **⚡ موتور جایگزین و رایگان (Google Translate Client):** امکان ترجمه آنی و بدون نیاز به کلید یا حتی بدون داشتن مدل لوکال.
- **📑 مدیریت هوشمند قطعات سند (Semantic Chunking):** تفکیک خودکار بندها و ساختار اسناد طولانی برای جلوگیری از سرریز حافظه LLM و حفظ لحن و یکپارچگی متن.
- **⚖️ ویرایشگر دوطرفه با اسکرول همگام (Split-Pane Workspace):** مشاهده همزمان متن اصلی (انگلیسی/چپ‌به‌راست) و ترجمه فارسی (راست‌به‌چپ) به همراه قابلیت ویرایش درجا.
- **✍️ تنظیمات پیشرفته لحن ترجمه:** پشتیبانی از لحن رسمی/دانشگاهی، روان و فارسی اصیل، ادبی و فصیح، و محاوره‌ای.
- **🔤 رعایت خودکار تایپوگرافی و نیم‌فاصله‌های فارسی:** اصلاح ساختار «می‌شود»، شناسه‌ها، افعال، پسوندها و یای اضافه در سراسر متن ترجمه.
- **📥 خروجی با فرمت‌های گوناگون:** دانلود خروجی به صورت Word (`.doc`)، Markdown (`.md`)، متن ساده (`.txt`) با UTF-8 BOM جهت باز شدن صحیح در نرم‌افزارهای آفیس ویندوز و پرینت/ذخیره مستقیم در قالب PDF.

## 🔠 مدیریت پیشرفته یونیکد و سازگاری با انکودینگ‌های ویندوز

برای تضمین عدم به‌هم‌ریختگی حروف و کاراکترها در محیط‌های گوناگون:
1. **تشخیص هوشمند انکودینگ (Smart Charset Detection):** اسناد متنی با انکودینگ‌های `UTF-8` (با و بدون BOM)، `UTF-16LE`، `UTF-16BE` و انکودینگ پیش‌فرض فارسی ویندوز (`Windows-1256 ANSI`) به صورت خودکار شناسایی و با استاندارد `NFC` بازخوانی می‌شوند.
2. **یکپارچه‌سازی فرم‌های نمایشی عربی/فارسی (Presentation Forms):** حروف متصل و گلیف‌های استخراج شده از اسناد PDF یا RTF به نویسه‌های استاندارد یونیکد تبدیل می‌گردند تا حروف شکسته یا ناخوانا نشوند.
3. **اسکریپت‌های سیستمی ۱۰۰٪ استاندارد و ایمن:** اسکریپت‌های دسته‌ای ویندوز (`.bat`) با استانداردهای ASCII بازنویسی شده‌اند تا در تمامی نسخه‌های ویندوز و کدهای زبانی بدون خطا و ارور syntax اجرا گردند.

## 🚀 نصب و اجرای سریع در ویندوز (۱ کلیک)

برای کاربران سیستم‌عامل ویندوز، فایل‌های اسکریپت آماده قرار داده شده است تا بدون نیاز به نوشتن دستورات در ترمینال، برنامه را نصب و اجرا نمایند:

### پیش‌نیاز:
نصب بودن **[Node.js](https://nodejs.org/)** (نسخه 18 یا بالاتر) روی ویندوز.

### مراحل نصب و راه‌اندازی:
1. مخزن را دانلود کنید (دکمه **Code** > **Download ZIP**) یا با Git کلون نمایید.
2. پوشه دانلود شده را از حالت فشرده خارج (Extract) کنید.
3. روی فایل **`INSTALL_WINDOWS.bat`** دابل‌کلیک کنید:
   - پکیج‌ها را به صورت خودکار نصب می‌کند.
   - تنظیمات لازم برای اتصال به Ollama را اعمال می‌نماید.
   - یک آیکون میانبر (Shortcut) روی دسکتاپ شما ایجاد می‌کند.
4. برای اجرای برنامه در دفعات بعد، کافیست روی فایل **`START_WINDOWS.bat`** (یا میانبر دسکتاپ) دابل‌کلیک نمایید تا برنامه و مرورگر به صورت خودکار باز شوند.

## 📦 بسته‌بندی و ساخت فایل نصبی دسکتاپ ویندوز (.exe)

این پروژه با **Electron** و **electron-builder** کاملاً یکپارچه شده و می‌توانید آن را به یک نرم‌افزار دسکتاپ نصبی (Setup Installer با فرمت NSIS) یا نسخه پرتابل (Portable) تبدیل کنید:

### روش ۱: ساخت خودکار با ۱ کلیک در ویندوز
روی فایل **`BUILD_WINDOWS_EXE.bat`** دابل‌کلیک کنید. این فایل مراحل کامپایل کدهای پروژه و ساخت بسته دسکتاپ را به صورت خودکار انجام داده و پوشه `release` حاوی فایل‌های `.exe` را باز می‌کند.

### روش ۲: ساخت از طریق ترمینال
```bash
# ساخت نسخه نصبی و پرتابل ویندوز (x64)
npm run dist:win

# یا ساخت اختصاصی نسخه پرتابل
npm run dist:portable
```
خروجی‌ها در مسیر زیر تولید می‌شوند:
- `release/Smart Translate SPA Setup 1.0.0.exe` (فایل نصبی ویندوز با قابلیت ایجاد آیکون دسکتاپ و استارت‌منو)
- `release/Smart Translate SPA-Portable-1.0.0.exe` (نسخه پرتابل بدون نیاز به نصب)

## 🎨 تایپوگرافی و طراحی Editorial Aesthetic

استایل‌های نرم‌افزار بر اساس راهنمای **Editorial Aesthetic** بازطراحی شده‌اند:
- **پالت رنگی شب عمیق (Midnight Slate):** پس‌زمینه‌های `#070d18` و سطوح پنل `#0a1120` به همراه کادرهای با کنتراست استاندارد `#1e3152`.
- **کنتراست بالای متون طولانی:** بهینه‌سازی رنگ متن اصلی به `#f8fafc` و متن‌های کمکی به `#94a9c9` جهت جلوگیری از خستگی چشم در مطالعه اسناد چند ده‌صفحه‌ای.
- **تایپوگرافی ویژه فارسی (Vazirmatn):** فاصله خطوط بهینه (`line-height: 1.95 - 2.1`) و تنظیم اتوماتیک نیم‌فاصله‌ها و یای اضافه.
- **تایپوگرافی انگلیسی (Inter):** فواصل حروفی بهینه‌شده (`letter-spacing: -0.015em`) برای متون مرجع.

## 🛠️ راهنمای نصب دستی و توسعه

اگر مایلید پروژه را از طریق ترمینال در ویندوز، لینوکس یا مک اجرا کنید:

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/your-username/smart-translate-spa.git

# ۲. ورود به دایرکتوری پروژه
cd smart-translate-spa

# ۳. نصب پکیج‌ها و وابستگی‌ها
npm install

# ۴. اجرای سرور توسعه محلی
npm run dev
```

سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
```
http://localhost:3000
```

## 🦙 راهنمای اتصال به Ollama و حل مشکل CORS

برای استفاده از مدل‌های آفلاین و لوکال Ollama در مرورگر، مرورگر نیاز دارد که مجوز دسترسی CORS را از سرور Ollama دریافت کند:

### الف) روش خودکار در ویندوز:
روی فایل **`OLLAMA_FIX_CORS.bat`** دابل‌کلیک کنید. سپس در صورت باز بودن Ollama، آن را یک‌بار ببندید و مجدداً باز کنید.

### ب) روش دستی در ویندوز (PowerShell):
دستور زیر را در PowerShell اجرا کرده و Ollama را ریستارت کنید:
```powershell
[System.Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', '*', 'User')
```

### ج) روش در لینوکس و مک (Linux / macOS):
```bash
# اجرای Ollama با متغیر مجاز برای کلیه مبداها
OLLAMA_ORIGINS="*" ollama serve
```

### مدل‌های پیشنهادی برای ترجمه به فارسی:
```bash
ollama run qwen2.5:7b       # کیفیت فوق‌العاده برای زبان فارسی
ollama run llama3.1:8b      # ترجمه روان و دقیق
ollama run gemma2:9b        # درک معنایی بالا
```

## 📄 فرمت‌های فایل پشتیبانی‌شده

| فرمت سند | پسوند | موتور استخراج |
| :--- | :--- | :--- |
| **PDF Document** | `.pdf` | استخراج لایه‌ای کلاینت با `pdfjs-dist` و اصلاح Presentation Forms |
| **Word Document** | `.docx` | تبدیل ساختاریافته به Markdown با `mammoth` و نرمال‌سازی NFC |
| **Markdown** | `.md` | پردازش مستقیم پاراگراف‌ها با دیکودر هوشمند UTF-8/UTF-16 |
| **کتاب‌های الکترونیکی** | `.epub` | استخراج فصول با کتابخانه `JSZip` و دیکودینگ جامع |
| **متن ساده** | `.txt` | استخراج با تشخیص انکودینگ خودکار (UTF-8, UTF-16, Windows-1256) |
| **اسناد وب** | `.html` / `.rtf` | تفکیک تگ‌ها و رمزگشایی کدهای هگزادسیمال و کاراکترهای یونی‌کد RTF |

## 🏗️ معماری و فناوری‌ها

- **فرانت‌اند:** React 19 + TypeScript + Vite
- **بستر دسکتاپ:** Electron + electron-builder (خروجی‌های NSIS Setup و Portable)
- **استایل و تایپوگرافی:** Tailwind CSS + Editorial Palette + قلم وزیرمتن (Vazirmatn) + اینتر (Inter)
- **موتور استخراج متن:** PDF.js, Mammoth.js, JSZip
- **ارتباط با هوش مصنوعی:** خط لوله مستقیم Fetch با استریم و صف Concurrency چندمسیره
- **بدون وابستگی به سرور Backend:** کارکرد کاملاً مستقل در کلاینت
